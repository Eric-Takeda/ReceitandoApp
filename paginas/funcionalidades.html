Funcionalidades do sistema

O App de Receitas foi desenvolvido para permitir que os usuários encontrem receitas, consultem seus detalhes, cadastrem preparações próprias e organizem suas receitas favoritas.

O aplicativo utiliza Flutter e Dart para sua interface e lógica, enquanto o Supabase é responsável pelos serviços de autenticação, banco de dados e armazenamento de imagens.

1. Cadastro e autenticação

O sistema possui funcionalidades de autenticação para identificar os usuários e permitir o acesso à sua conta.

  • Cadastro de uma nova conta.
  • Login com e-mail e senha.
  • Encerramento da sessão por meio da opção de sair.
  • Recuperação de senha por e-mail, conforme o fluxo configurado no projeto.

A autenticação é realizada pelo Supabase Auth. Após o login bem-sucedido, o usuário pode acessar o menu principal do aplicativo.

2. Menu principal

O menu principal funciona como ponto de acesso às funcionalidades do aplicativo.

A partir dele, o usuário pode acessar a área de receitas e iniciar o cadastro de uma nova receita. Outras opções, quando implementadas na interface, podem incluir o perfil e a lista de favoritos.

3. Consulta de receitas

A tela de receitas apresenta as preparações cadastradas no banco de dados. Cada item pode exibir informações como título, descrição, tempo de preparo, imagem e categoria.

Pesquisa

O campo de pesquisa permite localizar receitas pelo texto informado, facilitando a navegação quando existem várias opções cadastradas.

Filtro por categorias

As receitas podem ser organizadas por categorias, como:

  • Massas;
  • Carnes;
  • Sobremesas;
  • Saladas;
  • Bebidas.

A opção "Todas" permite visualizar receitas sem restringir a seleção a uma categoria específica.

Imagens das receitas

As imagens podem ser armazenadas no Supabase Storage. O endereço da imagem é associado à receita para que o aplicativo consiga carregá-la na interface.

4. Detalhes da receita

Ao selecionar uma receita, o usuário acessa uma tela com informações mais completas sobre a preparação.

Entre as informações que podem ser apresentadas estão:

  • Título e descrição;
  • Imagem da receita;
  • Tempo de preparo;
  • Quantidade de porções;
  • Ingredientes e respectivas quantidades;
  • Modo de preparo.

A tela também permite acessar ações relacionadas à receita, como favoritar e, quando permitido, editar ou excluir uma receita criada pelo próprio usuário.

5. Cadastro de receitas

A funcionalidade de cadastro permite que o usuário adicione suas próprias preparações ao aplicativo.

O formulário pode conter os seguintes dados:

  • Título da receita;
  • Descrição;
  • Tempo de preparo;
  • Quantidade de porções;
  • Ingredientes, quantidades e unidades;
  • Modo de preparo;
  • Imagem selecionada da galeria do dispositivo.

Depois do preenchimento, os dados são enviados ao Supabase para serem armazenados nas tabelas correspondentes. Quando uma imagem é selecionada, o arquivo é enviado ao bucket de imagens de receitas.

6. Edição e exclusão de receitas

O usuário pode editar ou excluir as receitas que criou, respeitando as permissões definidas no aplicativo e no banco de dados.

As receitas disponibilizadas previamente pelo sistema não devem permitir edição ou exclusão pelo usuário comum. Essa restrição ajuda a preservar o conteúdo original fornecido pelo aplicativo.

Quando uma imagem própria é substituída ou removida, o aplicativo também pode excluir o arquivo antigo do armazenamento, evitando manter imagens desnecessárias.

7. Receitas favoritas

A funcionalidade de favoritos permite que o usuário marque receitas para encontrá-las com mais facilidade posteriormente.

Os registros são armazenados na tabela favoritos, que relaciona o usuário à receita selecionada.

Cada registro utiliza o identificador do usuário e o identificador da receita. Dessa forma, é possível recuperar os favoritos associados à conta autenticada.

8. Perfil do usuário

A área de perfil reúne informações da conta e permite consultar ou atualizar os dados disponibilizados nessa tela.

As informações do perfil são armazenadas na tabela profiles. Caso o usuário selecione uma foto, o arquivo pode ser enviado ao bucket profile-images, enquanto o endereço correspondente é utilizado no perfil.

9. Integração com o Supabase

O Supabase conecta o aplicativo aos serviços necessários para seu funcionamento.

  • Supabase Auth: gerenciamento de autenticação e sessão.
  • PostgreSQL: armazenamento de receitas, ingredientes, categorias, favoritos e dados de perfil.
  • Supabase Storage: armazenamento de imagens de receitas e fotos de perfil.
  • Row Level Security (RLS): aplicação de regras de acesso aos dados, conforme as políticas configuradas.

Considerações finais

As funcionalidades do App de Receitas foram organizadas para facilitar a consulta, o cadastro e a organização de preparações culinárias. A integração entre Flutter e Supabase permite combinar uma interface interativa com armazenamento persistente de dados e imagens.

Esta documentação deve ser atualizada sempre que uma funcionalidade for alterada ou adicionada ao código definitivo do aplicativo.
