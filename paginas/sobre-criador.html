Sobre o projeto

O App de Receitas foi criado para facilitar a consulta e a organização de receitas culinárias. O sistema permite visualizar preparações, pesquisar por receitas, consultar ingredientes e modos de preparo e cadastrar receitas próprias.

O projeto utiliza Flutter e Dart no desenvolvimento da aplicação e Supabase para autenticação, banco de dados e armazenamento de imagens.

Objetivos de aprendizagem

Durante o desenvolvimento, o projeto busca proporcionar experiência prática com diferentes conceitos e ferramentas da área de tecnologia.

  • Desenvolvimento de interfaces com Flutter;
  • Programação utilizando a linguagem Dart;
  • Criação e integração com banco de dados;
  • Autenticação e controle de acesso;
  • Armazenamento e exibição de imagens;
  • Organização e documentação de um projeto de software.

Desafios durante o desenvolvimento

A construção do aplicativo envolve desafios como integrar a interface ao banco de dados, configurar a autenticação, gerenciar imagens e controlar as permissões de cada usuário.

A resolução desses desafios contribui para o aprendizado sobre o funcionamento de aplicações conectadas a serviços de backend e sobre a importância de testar cada funcionalidade.
